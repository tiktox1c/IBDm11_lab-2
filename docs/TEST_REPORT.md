## Полный набор тестов

Команда: `test.bat`.

**Результат: 18/18 тестов Node.js и 15/15 тестов Python, всего 33/33. Пропусков нет.**

### Node.js и JavaScript

- Обслуживание локальных файлов только по токену, кириллические имена, запрет POST.
- Защита от обхода пути через `..`, кодированные символы, обратные слеши и directory junction за пределы папки презентации.
- Шесть основных форматов тестовых презентаций, порядок и число кадров.
- Остановка при отсутствии перехода и неизвестной структуре.
- Сохранение структурно различных одинаковых слайдов.
- Ручная навигация одним контейнером по Space, обнаружение повторения кадра.
- Блокировка внешних ресурсов по умолчанию и их загрузка при явном разрешении.
- Ошибки локальных fetch-данных, отложенные изображения Reveal.
- Интерактивные элементы и захват девяти слайдов дополнительного примера.

### Python и интерфейс

- Реальный subprocess Node.js, запуск Chrome, PDF-экспорт и сообщения прогресса.
- Отмена во время захвата, очистка временных изображений, сохранение предыдущего результата.
- Ошибки недоступных ресурсов, пустые/повреждённые кадры и неверные настройки.
- Число и пропорции страниц PDF, порядок PNG в PPTX.
- Принудительный формат страницы с полями без растягивания изображения.
- Постраничная сборка PDF и отмена между страницами.
- Отсутствие наложения расширенных настроек на кнопки, сохранение размера окна.
- Видимость основной формы в обычном окне и прокрутка дополнительных полей.
- Реальная фоновая конвертация через GUI в трёхслайдовый PPTX при продолжающихся событиях окна.

Браузерные тестовые файлы выполняются последовательно. Параллельные браузерные нагрузки в одном из диагностических прогонов привели к превышению короткого тестового таймаута стабильности элемента; последовательный полный прогон прошёл успешно.

## Проверка интерфейса и запуска

Проверены окна 940×820, 1700×940 и 800×640, скрытие/раскрытие дополнительных настроек и закрепление действий внизу. Форма ограничена по ширине и центрируется в большом окне. На маленьком экране настройки доступны через прокрутку. Скриншот обычного окна находится в [README](../README.md).

Проверены `run.bat --check`, setup.bat в уже подготовленном окружении и синтаксис Python/JavaScript. Командные файлы имеют окончания строк CRLF, правило закреплено в `.gitattributes`.

## Исправления, подтверждённые проверками

1. Изображения Reveal проверяются на текущем слайде, а не на ещё не загруженных будущих слайдах. Текущий слайд загружается через API.
2. Ошибки локальных fetch/XHR препятствуют экспорту заглушек.
3. PDF собирается последовательно без удержания всех декодированных RGB-кадров в памяти.
4. Принудительные пропорции задают холст PDF/PPTX с пропорциональным размещением.
5. Отложенные Tcl-callback отменяются перед удалением окна.
6. CRLF в bat-файлах обеспечивает корректный разбор Windows cmd.
7. Временные HTML-фикстуры создаются внутри tmp, отдельно от постоянных примеров.
8. Для скрытых настроек и кнопок заданы отдельные строки компоновки. Прокрутка формы не перекрывает действия.

## Ограничения проверки

- PPTX не открывались вручную в настольном Microsoft PowerPoint: проверены структура OOXML через python-pptx, встроенные PNG, число слайдов и геометрия.
- Не подтверждены установка на другом чистом компьютере, все версии зависимостей и особые корпоративные политики Chrome.
- В GUI-тесте файловые диалоги заменены выбором тестовых путей. Само окно, фоновая конвертация, обновление событий и создание результата выполняются реально.
- Не заявляется поддержка произвольных HTML-презентаций. Неизвестная структура требует ручной настройки или отдельного адаптера.
- Видео, интерактивность и анимации экспортируются статическим кадром. Экспорт роликов/GIF или нативных анимаций PowerPoint в текущую версию не входит.

## Повторение проверок

Сначала установите приложение по README, затем зависимости разработки и локальные ресурсы Reveal:

```bat
set PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1
npm install --include=dev --ignore-scripts --no-audit --no-fund
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe tools\prepare_reveal.py
test.bat
.venv\Scripts\python.exe tools\verify_examples.py
```

Артефакты создаются в `test-results` и не входят в репозиторий.
